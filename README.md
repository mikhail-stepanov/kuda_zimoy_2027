# Январские каникулы в Азии

Готовый статический сайт для GitHub Pages. Загрузите index.html и папку assets в корень репозитория, затем Settings → Pages → Deploy from a branch → main → / (root).

Глобус вращается мышью и касанием; масштаб — колесом, жестом или кнопками. Кнопки маршрутов приближают нужные города. Все ресурсы локальные, API-ключи не требуются. Картографические данные: Natural Earth, public domain, низкая детализация. Линии показывают связь между городами, а не фактические трассы поездов или самолётов. Фотографии взяты из предоставленных скриншотов; права на публичную публикацию нужно проверить отдельно.

Исправленная версия: географическая текстура встроена в globe.js, поэтому карта работает и при локальном открытии без запросов к изображениям и без чтения Canvas.
